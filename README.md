## 每个方案包含

- `preview.png`：投稿预览图（核心图形、App Icon、字标、单色、深浅背景、24/48/96px）
- `mark.svg`：核心图形矢量源
- `mark-monochrome.svg`：单色版矢量源
- `app-icon-1024-color.svg` / `app-icon-1024.png`：1024×1024 App 图标
- `wordmark-horizontal.svg`：横版字标（含中文「蜜蜂记账」）
- `on-light.svg` / `on-dark.svg`：浅色 / 深色背景版本
- `usage-mockup.png`：App 图标与品牌应用场景效果图

## 素材与 AI 辅助披露

无第三方图形素材；字标使用系统字体 Arial（拉丁）与 Microsoft YaHei / PingFang SC（中文），未打包字体文件；SVG 几何路径与说明文案由 AI 辅助生成，并经人工筛选、精修与逐项校验；配色、造型与构图为原创。
